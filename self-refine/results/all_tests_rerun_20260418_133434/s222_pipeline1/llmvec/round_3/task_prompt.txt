        The issue is that the `a[]` loop adds `bc` then subtracts `bc`, making it a no-op — but the original `s222` kernel is:

```

```
followed by a second loop:
```

```

These two loops run **sequentially over the full array**, not interleaved per element. Because the vectorized code does `+= bc` then `-= bc` for the **same element in the same iteration**, it cancels out and leaves `a[]` unchanged. The original does all additions first, then all subtractions — which also cancels, but only if `b` and `c` haven't changed.
