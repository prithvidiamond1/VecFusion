- The ternary operator `? :` cannot be used directly with vector types in C; need to replace it with a conditional select using bitwise operations.
- Change line `min_vec = (mask ? current_vec : min_vec);` to `min_vec = (mask & current_vec) | (~mask & min_vec);` or equivalent vector blend.
- Ensure the mask is cast to an appropriate integer vector type for bitwise operations if necessary, but since `mask` is already a vector of floats from the comparison, convert it to an integer vector for bitwise AND.
- Specifically, use `__builtin_convertvector(mask, v8i32)` or cast via `(v8i32)mask` before bitwise operations, then cast back to `v8f32` after blending.

- This ensures the ternary is replaced with a vector-safe bitwise blend.
