        Tester feedback:
        The candidate has a **semantic error** in the tail handling loop.  

- The main vector loop computes a **prefix sum** where each `b[i]` depends on the cumulative sum up to that point.  
- The tail loop incorrectly starts with `running_sum = vec_sum[3]` (the last element of the vector sum), but then does `running_sum += a[i]` — this **double-counts** the last element of the vector chunk.  
- Fix: the tail loop should **not** add `a[i]` again for the first tail element; it should continue from the last computed `b[i-1]` value.
