Looking at the failures:

- **Off-by-one in array indexing**: The loop writes `src[i+1]` and `dst[i+1]` starting at `i=0`, but the first element `src[0]`/`dst[0]` is never written. The correct pattern should write `src[i]`/`dst[i]` for the current point, starting at index 0 (i.e., `src[0] = srcStart`, `dst[0] = dstStart` before the loop, then write `src[i+1]`/`dst[i+1]` inside).

- **Missing initialization of `src[0]` and `dst[0]`**: Before the loops, add `src[0] = srcStart; dst[0] = dstStart;` so index 0 is populated.

- **Final sentinel indices are wrong**: The last entries should be at `divCount + 1` only if indices 1..divCount are used for divs. But since we're writing `src[i+1]` for `i` in `0..divCount-1`, the sentinel should be at `src[divCount]`/`dst[divCount]`, not `src[divCount+1]`/`dst[divCount+1]`. Change to `src[divCount] = srcEnd; dst[divCount] = dstEnd;` — wait, actually with `src[0]=srcStart` and writing `src[i+1]` for i=0..divCount-1, the sentinel is correctly at index `divCount`, not `divCount+1`.

- **Unrolled loop writes `src[i+4]`/`dst[i+4]` which can exceed bounds**: When `i+3 < divCount`, writing `src[i+4]` is fine only if `i+4 <= divCount`. This is consistent with the scalar loop writing `src[i+1]`.

- **`isScalableInt` is not toggled in the unrolled loop's parity tracking**: After 4 iterations the parity is the same, which is correct — but the *starting* parity for the next group of 4 must match the actual iteration parity. Since `isScalableInt` starts at `isScalable` and toggles each iteration, after `i` iterations it equals `isScalable ^ (i & 1)`. The unrolled loop doesn't update `isScalableInt` between groups, so if `isScalable` is odd-parity at the start of a group, `s0` should be `isScalableInt` (which is correct only if it was updated). **Fix**: after each group of 4, `isScalableInt` stays the same (4 flips = no change), so no update needed — this is actually correct.

**Concrete fixes:**

- Add before the loops: `src[0] = srcStart; dst[0] = dstStart;`
- Change `src[divCount + 1] = srcEnd; dst[divCount + 1] = dstEnd;` → `src[divCount] = srcEnd; dst[divCount] = dstEnd;`
- In the unrolled loop, change all `src[i+1]..src[i+4]` → `src[i+0]..src[i+3]` and `dst[i+1]..dst[i+4]` → `dst[i+0]..dst[i+3]`, adjusting delta accumulation accordingly (write `dst[i+0] = curDst + dstDelta0`, etc.)
- In the scalar loop, change `src[i+1] = d; dst[i+1] = curDst + dstDelta;` and `curDst = dst[i+1]` → write to `src[i+1]`/`dst[i+1]` but keep `curDst` update — actually the scalar loop indexing is consistent with writing the *next* point, so keep it but ensure `src[0]`/`dst[0]` are initialized as above.
